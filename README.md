# catcmd
Если cmd не работает можно воспользоватся catcmd
Требуется c++ из серии .NET 10

> [!WARNING]
> Может не запустится или антивирус пометит как подозритеельное из за скрытой команды чтобы работало отображение!

> [!CAUTION]
> НЕ ВВОДИТЕ ОПАСНЫЕ КОМАНДЫ ОНИ ПОВЛЕКУТ К ПОТЕРИ ДАННЫХ, АВТОР НЕ НЕСЕТ УЩЕРБ!

> [!NOTE]
> При ошибке не найдено и тд будет кастомная ошибка.

> [!TIP]
> А зачем вообще это скачивать? cmd всгда работает!

> [!IMPORTANT]
> Не является оригинальным cmd!
